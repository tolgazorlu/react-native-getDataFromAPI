# React Native: Get Data from API

A minimal Expo/React Native app that fetches JSON from a remote URL and renders it in a list.

## About

Built July 2021 as a learning exercise for data fetching and `FlatList` rendering in
React Native.

## Features

- Fetches a JSON array (`cars.json`) from a GitHub-hosted URL on mount
- Shows a loading spinner while the request is in flight
- Renders the results in a `FlatList` with an image and title/model text

## Tech Stack

- React Native (Expo SDK 42), React, `expo-status-bar`

## Getting Started

```sh
npm install
npm start      # expo start
npm run android
npm run ios
npm run web
```

## Status

Learning project, not maintained.
